The project is aimed to **protect your personal files in your Windows PC at kernel level**.*Of course for those stored at public windows devices(if your personal operations was allowed)*

该项目旨在**为你在你的Windows PC上的个人文件提供内核级别的文件防护**,*当然同样适用于存在公共Windows设备的那些(如果你个人的操作被允许)*

Through the project was developed from grade Senior 1. At present, the anti-deletion function is only implemented in a rough way, not all expected functions :(

因为项目是在高一时启动的.目前仅以一种粗糙的方式实现了防删除功能,并非全部预期功能 :(
